# PulseIQ — Data Analytics Project

PulseIQ is a multi-phase data analytics project focused on data engineering, data quality, governed metrics, business analytics, and interactive dashboards.

## Project Structure

### Phase 1: Foundation

| Task | Description |
|---|---|
| Task 1 | ETL Pipeline |
| Task 2 | Analytics Warehouse |
| Task 3 | Data Quality Gatekeeper |
| Task 4 | Governed Metric Layer |
| Task 5 | Workforce Insights Dashboard |

### Phase 2: People and Teams

| Task | Description |
|---|---|
| Task 6 | Attendance and Leave Analytics |
| Task 7 | Attrition Analytics |
| Task 8 | Team Productivity Analytics |
| Task 9 | Payroll Reconciliation |
| Task 10 | Budget and KPI Performance Analytics |

## Technology Stack

- Python
- SQL
- pandas
- DuckDB
- Streamlit
- Git and GitHub
